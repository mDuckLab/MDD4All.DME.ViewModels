The view models of MDD4All.DME, an editor for object graphs.

They build a tree from whatever object they are handed - properties, lists, arrays,
dictionaries, and the values at the leaves - without knowing the type beforehand. Around
that sit the open document and its unsaved state, the settings, and the rules a data
model declares through its annotations.

Written for MDD4All.DME and shaped by it. Useful elsewhere only where something is built
along the same lines.
